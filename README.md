# Data-story-from-2022-Kaggle-Machine-Learning-Data-Science-Survey
The project aims to tell a data story by conducting an exploratory data anlalysis on the data collected from "2022 Kaggle Machine Learning & Data Science Survey" along with employing ordinal classification models. The repository contains a 3 page report that summarizes the findings of the project along with the jupyter notebook file to showcase the code work.
